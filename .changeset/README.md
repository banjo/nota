# Changesets

Every pull request that changes what users get adds a changeset: `bunx changeset`, pick
`@nota/desktop` (it carries the version of the whole product: app, CLI and web), choose
**patch** and write one line for the release notes. Changes that don't ship (CI, docs, tests)
need none.

See [RELEASE.md](../RELEASE.md) for how changesets become a release.
